# Unravel frontend

React/Vite UI for Unravel.

From the `byline/` frontend directory:

```bash
npm ci
npm run dev
npm run typecheck
npm test
npm run build
```

The frontend depends on the Python API in `apps/ravel/` for local application data and actions.

Design-system attribution: the original Figma Make Design System Foundation work and its shadcn/ui components are credited in [ATTRIBUTIONS.md](byline/ATTRIBUTIONS.md).
